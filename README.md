# Data Scientist Mastery

A structured learning repository to help you master the skills required for a Data Scientist role in a modern consulting environment like Equal Experts.

This repo covers:
- Python for data work
- SQL and data modeling
- Statistics and experimentation
- Machine learning and model evaluation
- MLOps and deployment basics
- Git/GitHub workflow and CI/CD
- Business communication and stakeholder collaboration
- End-to-end project execution

## Learning roadmap

| Area | Focus | Priority |
| --- | --- | --- |
| Python | Data structures, pandas, NumPy, plotting | High |
| SQL | joins, aggregations, window functions, performance | High |
| Statistics | probability, inference, A/B testing, sampling | High |
| ML | supervised learning, validation, feature engineering | High |
| MLOps | pipelines, reproducibility, deployment | Medium |
| Git & CI/CD | version control, PRs, automation | High |
| Communication | stakeholder updates, experiments, business impact | High |
| Projects | portfolio-ready projects with business context | High |

## Suggested study order

1. Foundation: Python + SQL + statistics
2. Data wrangling and EDA
3. Classical ML and model evaluation
4. Deep learning and NLP basics
5. MLOps, governance, and deployment concepts
6. Git, CI/CD, and collaborative workflows
7. Projects and interview prep

## Repository structure

- `python/` — Python for data science exercises
- `sql/` — SQL problems and sample queries
- `statistics/` — probability and inference practice
- `ml/` — machine learning concepts and starter notebooks/scripts
- `git/` — Git workflow and commands
- `cicd/` — CI/CD and deployment basics
- `mlops/` — reproducible ML operations and model lifecycle
- `projects/` — project ideas and starter templates
- `interview/` — interview prep and technical questions
- `templates/` — reusable templates for tasks and reports

## Recommended setup

- Python 3.11+
- VS Code or PyCharm
- Git + GitHub
- Jupyter Notebook / VS Code notebooks
- Conda or virtualenv
- PostgreSQL or SQLite for SQL practice
- scikit-learn, pandas, numpy, matplotlib, seaborn

## Quick start

```bash
python -m venv .venv
source .venv/bin/activate  # Linux/macOS
# .venv\Scripts\activate  # Windows
pip install -r requirements.txt
```

## Core skills checklist

Before applying for a Data Scientist role, you should be comfortable with:

- writing clean Python
- cleaning and exploring data
- building and validating ML models
- explaining model trade-offs clearly
- working with SQL and data pipelines
- collaborating with product, engineering, and business stakeholders
- communicating results with business impact
