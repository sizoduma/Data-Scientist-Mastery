# Git and Version Control

Git is core to modern team workflows. A Data Scientist must be able to work with shared code, branches, PRs, and reproducibility.

## Topics
- git init, clone, add, commit, push
- branching and merging
- pull requests
- rebase and merge strategies
- conflict resolution
- GitHub flow and trunk-based development
- commit hygiene and code review

## Starter guide
See `git/cheatsheet.md`.

## Common commands
```bash
git status
git checkout -b feature/experiment
git add .
git commit -m "Add baseline model"
git push origin feature/experiment
git fetch origin
git merge origin/main
```
