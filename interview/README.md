# Interview Preparation

This folder is for data science technical interview practice and role-aligned questions.

## Core topics
- SQL interview questions
- feature engineering reasoning
- model trade-offs
- metrics selection
- experiment design
- product/business communication

## Example questions
1. What is the difference between accuracy and precision/recall?
2. How do you handle imbalanced classes?
3. Explain a time you had to explain a model to non-technical stakeholders.
4. How do you evaluate whether a feature is useful?
5. What metrics would you use for a churn model?
6. How do you know whether a model is overfitting?

## Daily practice plan
- 1 SQL question
- 1 statistics question
- 1 ML model question
- 1 business communication prompt
