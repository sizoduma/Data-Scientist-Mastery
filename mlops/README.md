# MLOps Basics

Machine learning projects need more than a good model. They need reproducibility, monitoring, and clear ownership.

## Topics
- experiment tracking
- model registry
- feature store concepts
- reproducible pipelines
- model monitoring
- retraining triggers
- governance and drift detection

## Starter concepts
- Training code should be versioned and deterministic
- Data schema and feature transforms should be tracked
- Model performance should be monitored in production
- Retraining decisions should be supported by business and technical metrics

## Example checklist
1. Version training data
2. Store model metadata
3. Log metrics and predictions
4. Validate input data before serving
5. Monitor drift and business impact
