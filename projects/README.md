# Projects and Portfolio Ideas

The best way to master the role is to build end-to-end projects that resemble real business work.

## Project 1: Customer churn prediction
- Define the business question
- Prepare labels and features from historical data
- Train and compare models
- Explain results and recommend actions

## Project 2: Recommendation dashboard
- Analyze user behavior
- Build a ranking model or similarity-based recommendation
- Evaluate business metrics like click-through or conversion

## Project 3: Sales forecast model
- Build time-series forecasting workflow
- Incorporate seasonality and promotions
- Evaluate MAE/MAPE and stakeholder communication

## Project 4: Fraud detection
- Handle class imbalance
- Choose appropriate metrics
- Build alerting and monitoring recommendations
